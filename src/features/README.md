# Feature boundaries

Catalog owns destination/tour reads, search/query behavior and quote links. Navigation owns public menu links; all Phase 2 preview contracts have been replaced by explicit routes. Content owns the typed service/About/contact/policy read boundary. Inquiries owns shared schemas, recognized prefill, unavailable submission contracts and the server-held confirmation boundary. Phase 4 forms validate locally without transmitting or saving personal details. Supabase/persistent intake/auth remain Phase 5; CMS and staff workflows remain later phases. Keep database access server-only; no business submission is simulated. See the roadmap and `docs/PHASE_4_PUBLIC_PAGES.md` before adding functionality.
